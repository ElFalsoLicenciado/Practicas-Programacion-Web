Idea del cliente:
Una página de aprendizaje donde se guarde el avance que llevan los alumnos, que instru-
mento es el que están aprendiendo y una sección de comentarios para futuros cambios en
la página, es necesario pedir un acceso el cual será gratuito, pero también una sección en
caso de que les gustaría a los usuarios dar un apoyo a los usuarios dar un apoyo para el
mejoramiento de la página.
Objetivo principal:
Crear una página web para poder garantizar un aprendizaje correcto de marchas y toques
de la banda de guerra de una manera general y fácil de aprender.
Objetivos específicos:
Una base de datos para poder registrar al usuario y su debido avance.
Diferentes interfaces de acuerdo al instrumento.
Sección de pago.
Sección de comentarios.
Poder realizar modificaciones en el futuro.
